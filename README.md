# LGPD Audio - privacy redaction for audio recordings (case study)

*The full source code is private. This page describes the project, the architecture and a few sanitized code samples.*

## Overview

LGPD Audio takes an audio recording (uploaded or captured in the browser), transcribes it with word-level timestamps, detects personal and sensitive data as defined by Brazil's data protection law (LGPD, Law 13.709/2018), covers the matching segments of the audio with a beep, and exports a report to .docx.

## What I built

**Transcription:** speech-to-text with word-level timestamps using OpenAI Whisper, with an IT glossary added to the prompt to improve recognition of technical terms.

**Sensitive data detection:** a detector that finds personal and sensitive spans in the transcript.

**Audio censoring:** the timestamps of each detected span are used to replace exactly the matching audio intervals with a beep. The original speech is replaced, not just overlaid, so it is never audible under the tone.

**Reporting:** a .docx report export, with a short report title generated by an LLM (optional).

**Web app:** a FastAPI service with a simple browser UI, health check and environment-based configuration.

## Design decision: safety margin around every span

Word timestamps from speech-to-text can be slightly imprecise. If a sensitive word is cut a few milliseconds late, part of it stays audible. To avoid this, each detected span is padded, clamped to the audio length, and overlapping spans are merged before the beep is generated. When in doubt, the pipeline over-censors instead of under-censoring.

## Code sample (simplified)

```python
def merge_ranges_ms(time_ranges, padding_s, duration_ms):
    """Pad each detected span, clamp it to the audio length and merge overlaps."""
    padded = []
    for start_s, end_s in time_ranges:
        start_ms = max(0, int((start_s - padding_s) * 1000))
        end_ms = min(duration_ms, int((end_s + padding_s) * 1000))
        if end_ms > start_ms:
            padded.append((start_ms, end_ms))
    padded.sort()

    merged = []
    for start_ms, end_ms in padded:
        if merged and start_ms <= merged[-1][1]:
            merged[-1] = (merged[-1][0], max(merged[-1][1], end_ms))
        else:
            merged.append((start_ms, end_ms))
    return merged
```
